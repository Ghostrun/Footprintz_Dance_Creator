A program designed to allow users to create dance formations with an easy way to share with others.
"Create New Dance" brings users to a page to create their own dance. 
"Show Ghosts?" allows users to see the previous positions of everyone. 
"SAVE" button saves current dance to device.
"Load Dance" brings users to a page to select saved dances. 
Click on the name of a dance to copy its code to the clipboard, click "Enter Code", paste code into provided box to then view that dance.
"Show text to copy?" allows users to manually copy text after clicking a dance in case it does not copy otherwise.
"Add Dance" allows users to enter the code and then name of a new dance they want to save to their device.
Sharing? Send dance code and name to friends so they can add your dance to their device using the "Add Dance" button after clicking "Load Dance". Dance code needs to be exact, but name can be changed.
"Phone?" changes sizing slightly to look better on phone screens.

Originally created for the Messiah University Footprintz dance team.
